# Google Play: личный аккаунт, организация и оплата

Проверено по официальным страницам Google 13.11.2026.

Для индивидуального разработчика Mapuga подходит **personal developer account**. Создавать юридическое лицо только ради публикации обычного приложения с картой и рекламой Google не требует. Personal accounts могут монетизировать приложения. Казахстан поддерживается для регистрации разработчика и AdMob.

**Play Console стоит US$25 однократно за аккаунт**, не $50. Это не ежегодная подписка и не плата за каждое приложение. Пересчёт валюты и возможные комиссии банка определяются при оплате. Регистрационный платёж не покупает «вечную публикацию»: аккаунт и приложения должны выполнять действующие правила, проходить проверки и обновляться.

## Personal и organization

| Personal | Organization |
| --- | --- |
| Для индивидуального разработчика; допустима монетизация. | Когда аккаунт представляет организацию/бизнес. |
| Проверка личности; D-U-N-S не нужен. | Проверка организации и обычно D-U-N-S; для отдельных случаев есть исключения. |
| Для нового аккаунта — дополнительные условия тестирования и подтверждение Android-устройства. | Дополнительные сведения об организации и контактах. |

Google отдельно требует organization account для ряда категорий, включая финансовые сервисы, определённые приложения здоровья, приложения с VpnService и государственные приложения. Обычный планировщик маршрутов сам по себе в перечисленные категории не входит. Если позднее аккаунт будет представлять компанию, следует использовать подходящий organization account и проверить актуальные требования.

Новый personal account, созданный после 13.11.2023: закрытое тестирование с минимум **12 участниками, непрерывно подписанными не менее 14 дней**, затем заявка на production access. Само истечение 14 дней не гарантирует одобрения. Также потребуется проверка доступа к Android-устройству через приложение Play Console и другие проверки регистрации.

## Реклама и доход

У AdMob есть тип **Individual** с выплатами на имя владельца; корпоративный рекламный аккаунт не является общим требованием для рекламной монетизации. Нужны проверка аккаунта/приложения, корректные платёжные сведения и выполнение правил. Регистрация Play Console не включает оплату карт, API, сервера и не гарантирует рекламный доход.

Тип аккаунта Google **не определяет налоговый статус в Казахстане**. Нужность ИП/другой формы деятельности, декларирование и налоги по доходу от рекламы следует отдельно проверить по действующему законодательству Казахстана. Этот документ описывает правила платформ Google, а не даёт налоговое заключение.
