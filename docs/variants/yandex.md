# Mapuga / Яндекс Карты

HTML: dist/variants/yandex.html

JS API v3, suggest → search после выбора, Router. Наличие бесплатной карты не означает бесплатную маршрутизацию и право выпускать самостоятельный навигатор.

Проверено: 2026-11-13.

1. Подключить продукты JS API, Геосаджест, Геокодер и Router; задать разрешённый HTTP Referer, включая localhost для теста.

2. Map hits бесплатны. Router по опубликованному месячному тарифу — от 20 800 ₽ за 1000 ответов/сутки; trial 7 дней по 100 ответов/сутки. Остальные продукты учитываются отдельно.

3. Suggest и геокодер имеют собственные бесплатные лимиты и правила. 195 000 ₽/год у JS API относится к панорамам, а не к обычной загрузке карты.

4. Текущие условия ограничивают похожие на Яндекс Карты приложения, realtime monitoring и сохранение данных (кроме разрешённого технического кеша). Для самостоятельной Mapuga-навигации нужно согласовать лицензию/NaviKit.

5. Этот HTML — планировщик без GPS-ведения, GPX и постоянного сохранения API-ответов. Логотипы, атрибуция и кнопка «Открыть в Картах» должны оставаться доступными.
