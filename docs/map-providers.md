# Карты и справочники организаций для Mapuga

Условия проверены 13 ноября 2026 года. Сейчас фон карты загружается из OpenStreetMap, адреса — из Photon на данных OSM, автомобильный путь — из OSRM. Ошибка вроде «ночной клуб вместо супермаркета» может означать устаревшую запись организации в OSM. Конкретный объект без его проверки не исследовался. Другая цветовая тема или другой рендерер тех же данных не обеспечивают обновление названия организации.

Для исправления данных можно использовать ссылку «Сообщить об ошибке карты» в Mapuga. Для перехода на другой каталог понадобится интегрировать источник организаций/адресов, а при необходимости и SDK карты, а не только поменять URL тайлов.

| Вариант | Бесплатность API | Что учитывать в Mapuga |
| --- | --- | --- |
| **2ГИС** | Бесплатный демо-ключ на месяц; дальнейший стандартный доступ по подписке | Подходит как кандидат для проверки местных организаций. Без сравнения конкретных адресов нельзя гарантировать, что любое заведение актуальнее, чем в OSM. [Доступ и подписки](https://docs.2gis.com/platform-manager/subscription/purchase), [исправления справочника](https://help.2gis.ru/question/kak-soobshchit-ob-oshibke-v-2gis). |
| **Google Maps Platform** | Есть бесплатные месячные квоты: например, Dynamic Maps — 10 000 событий. Нужны API-ключ и подключённый billing; сверх квот — платно | У поиска адресов, Places и Routes отдельные SKU и лимиты. Можно рассматривать пилот с ограниченными квотами; бесплатность приложения для пользователя не исключает расходов разработчика. [Тарифы](https://developers.google.com/maps/billing-and-pricing/pricing), [JS API и billing](https://developers.google.com/maps/documentation/javascript/usage-and-billing). |
| **Яндекс Карты** | Есть бесплатное использование при выполнении условий и лимитов; сервисы подключаются отдельно | Бесплатные условия требуют открытого доступа, ограничивают сохранение полученных через API данных и запрещают мониторинг местоположения транспорта/мобильных сотрудников в реальном времени. В Mapuga есть сохранение адресов и GPS, поэтому совместимость конкретного сценария и лицензии нужно уточнить до интеграции. Нельзя обещать прямую бесплатную замену без изменений приложения. [Бесплатные условия](https://yandex.ru/dev/commercial/doc/ru/), [актуальные условия сервисов](https://yandex.ru/legal/maps_api/ru/), [изменения тарифов](https://yandex.ru/maps-api/docs/news/new-billing/free-usage.html). |
| **Текущий OSM + Photon + OSRM** | В прототипе работают без ключей, на публичных серверах с ограничениями | Данные организаций зависят от наполнения OSM. Переключение на другую карту на тех же данных не является гарантией свежести. Для заметной нагрузки нужны согласованный провайдер или своя инфраструктура. Правила сервисов приведены в README. |

Для Караганды разумно сначала сравнить 2ГИС и Яндекс на нескольких известных публичных адресах: вывески, тип организации, входы и номер дома. Это предложение проверки, а не результат проведённого сравнения. Затем можно выбрать лицензию под сохранение маршрутов и GPS. Если важен бесплатный пилот с небольшим числом пользователей, Google также стоит оценить по отдельным квотам карты, поиска и маршрутов.

Автоматического переключения на 2ГИС, Google или Яндекс в текущей версии нет. Ключи и платёжные аккаунты не создавались.
