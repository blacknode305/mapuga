# Mapuga

HTML-прототип бесплатного планировщика автомобильных маршрутов по адресам. Базовая версия работает без ключей; отдельные варианты позволяют сравнить пять поставщиков карт и расходы на API. Android SDK и сборщик для запуска HTML не нужны.

## Отдельное демо для организаций

**[dist/fleet-demo.html](dist/fleet-demo.html)** — самостоятельный корпоративный сценарий. После `npm start` откройте **http://127.0.0.1:4173/fleet-demo.html**. Личная Mapuga и пять вариантов API не менялись ради бизнес-демо.

В демо можно локально зарегистрировать поставщика или получателя, добавить машины, составить маршрут из адресов Караганды, назначить его машине и открыть доступ выбранным партнёрам. Получатель видит поставки разных организаций, но только разрешённые рейсы. Начальные вымышленные организации и машины уже добавлены.

Нажмите «Запустить демо», затем «Открыть экран получателя». Вкладки **одного браузера и одного origin** синхронизируются через localStorage/BroadcastChannel. Не смешивайте localhost и 127.0.0.1: это разные origin. Отзыв доступа убирает рейс из интерфейса получателя. Движение — симуляция ×10, **не реальный GPS**; исходные пунктирные траектории условные. Новые маршруты строятся по дорогам через OSRM.

Переключатель организаций показывает UX, **не защищает данные**: всё хранится в одном браузере и доступно его владельцу. Настоящие аккаунты, изоляция организаций на сервере, отправка GPS с телефона, общий доступ между устройствами и WebSocket/SSE здесь не реализованы. Не вводите реальные персональные данные в публичный тестовый стенд.

- [Сценарий тестирования и следующий этап](docs/fleet-demo.md).
- [Личный аккаунт Google Play, цена и реклама](docs/play-console-account.md).
- **[Описание каждого файла репозитория](docs/files.md)**, обновление: `npm run docs:files`.

**Под каждым HTML-демо размещены требования, тарифные ссылки и ограничения.** Страницы с ключами не подменяют выбранный сервис OSM-картой, пока ключа нет. Ключ вводится только в память вкладки и не сохраняется. Ключи нужны вам как разработчику для сравнительного стенда; в будущем опубликованном Android-приложении пользователь не должен вводить API-ключ и платить за основные функции.

- [Интерактивный калькулятор](dist/variants/calculator.html): рекламные показы, fill, доля аудитории, условный eCPM, тайлы, autocomplete, маршруты, тарифы и результат при 10/100/1000/10000 DAU.
- [Расчёты с исходными допущениями](docs/monetization.md). При неизвестной полной цене 2ГИС/Яндекса результат показывается как неизвестный, а не бесплатный. Валюты без курса не суммируются.
- [План Google Play и рекламы](dist/variants/play-market.html): target API, AAB, testing, privacy/Data safety, AdMob и дополнительный вариант Яндекс Mobile Ads. Реклама предлагается на отдельном экране после поездки, без рекламного барьера для функций и без показов во время активного ведения.

**Проверка:** обработчики SDK и форматов, финансовая арифметика и proxy проверяются тестами. Живые Google/Geoapify/2ГИС/Яндекс без ваших ключей не проверены. Карта, поиск, маршрут и демо OSM доступны без ключа. Это не AAB, не реальная рекламная интеграция и не опубликованное приложение.

### Локальный Routing proxy 2ГИС

Если Routing key серверный или прямой browser POST блокируется CORS, задайте переменную окружения перед запуском:

```powershell
$env:MAPUGA_2GIS_ROUTING_KEY = 'ВАШ_СЕРВЕРНЫЙ_КЛЮЧ'
npm start
```

В 2ГИС HTML заполните ключ карты и Suggest; Routing browser key оставьте пустым. Запрос пойдёт в `/api/2gis/route`. Proxy передаёт только проверенные 2–10 точек на фиксированный официальный endpoint, скрывает серверный ключ и ограничивает запросы. Этот сервер слушает только loopback и предназначен для локального теста. Публичный proxy потребует отдельного хостинга, HTTPS, защиты ключа и общего контроля расхода. `.env` автоматически не загружается.

## Запуск

HTML, стили, скрипты и Leaflet лежат локально в `dist/`. Для карты, подсказок и расчёта пути нужен интернет.

Рекомендуемый вариант с постоянным адресом и предсказуемым сохранением в браузере — локальный сервер (Node.js 20+):

```powershell
cd D:\code\mapuga
npm start
```

Откройте http://127.0.0.1:4173. Установка npm-зависимостей не требуется. Сервер принимает подключения только с этого компьютера. Для другого порта задайте переменную `PORT`.

Файл `dist/index.html` также можно открыть двойным щелчком, если браузер разрешает внешние запросы со страниц `file://`. Проверенный вариант — запуск через локальный HTTP-сервер; прямое открытие файла не проверено из-за запрета `file://` во встроенном браузере среды разработки.

Список остановок сохраняется в `localStorage` конкретного браузера и адреса страницы. `file://`, `localhost` и `127.0.0.1` имеют раздельное хранилище; при переезде между ними список не переносится. Некоторые браузеры ограничивают сохранение при открытии через `file://` или в приватном режиме.

## Как пользоваться

1. Выберите страну и город. По умолчанию — Казахстан, Караганда. В поле страны вводите первые символы и выбирайте подсказку: например, `каз`, `рос`, `бел`, `KZ`, `қаз`. Совпадения в начале названия идут перед совпадениями внутри; поддерживаются альтернативные названия на русском, английском и некоторых местных языках. Выбор доступен мышью или стрелками и Enter, Escape/Tab возвращают ранее выбранную страну без изменения маршрута. В справочнике 12 стран и 44 города: Казахстан, Кыргызстан, Узбекистан, Россия, Беларусь, Армения, Азербайджан, Таджикистан, Туркменистан, Молдова, Грузия и Украина. Это начальный справочник, а не полный список городов мира.
2. Введите минимум три символа улицы, затем номер дома. Например, `Бухар Жырау 50`. Выберите результат мышью или стрелками и Enter. Текст запроса сам по себе не становится адресом.
3. Первый выбранный адрес становится стартом. Добавляйте остановки, до 20 точек включительно. Если дом не найден в OSM, включите «Или выберите точку на карте» и нажмите на нужное место.
4. Меняйте порядок кнопками ↑ ↓. Первая строка всегда является начальной точкой, последняя — финишем.
5. Нажмите «Построить маршрут». Линия следует автомобильным дорогам в порядке списка. Показываются общие расстояние и время, а также расстояние и время каждого участка.
6. При необходимости скачайте GPX с путевыми точками и геометрией рассчитанного маршрута.

## Геолокация и подсказки поворотов

1. Если нужно ехать от текущего положения, нажмите «Добавить мою позицию в начало» и разрешите геолокацию. Эта точка добавляется перед существующими адресами; повторное нажатие обновляет её. Город должен соответствовать вашей позиции.
2. Постройте маршрут. В блоке результата появятся «Озвучивать повороты», «Начать навигацию» и «Проверить без GPS · демо».
3. Нажмите «Начать навигацию». Mapuga использует `watchPosition` с высокой точностью, показывает синий маркер и точность GPS, сопоставляет позицию с геометрией дороги на устройстве и выводит следующий манёвр.
4. При приближении к манёвру озвучиваются предупреждения примерно за 300, 80 и 25 метров — не повторяясь на каждом обновлении координат. Есть русские инструкции для левого/правого поворота, разворота, развилки, съезда и кругового движения.
5. На промежуточном адресе нажмите «К следующей остановке». На последнем адресе слежение прекращается автоматически. Кнопка остановки, изменение списка и закрытие страницы также прекращают слежение и убирают очередь речи.

Проверить интерфейс дома можно кнопкой «Проверить без GPS · демо». Маркер проедет по рассчитанному пути в ускоренном режиме; карточка явно помечена как демонстрация. Реальная геолокация при этом не запрашивается. Озвучку можно выключить перед запуском.

При перетаскивании карты слежение за маркером отключается; кнопка «Вернуться к позиции» включает его снова. При скрытии вкладки навигация приостанавливается, GPS-watch закрывается, речь отменяется. После возвращения приложение ждёт свежую позицию и продолжает текущий маршрут.

**На телефоне нужен HTTPS и разрешение геолокации.** `http://127.0.0.1`/`localhost` подходит для разработки на том же компьютере; обычный `http://192.168…` с другого устройства не является заменой HTTPS. Держите экран включённым и вкладку открытой: эта версия не работает как фоновый Android-навигатор. [Требования Geolocation API](https://www.w3.org/TR/geolocation/), [watchPosition](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/watchPosition).

При точности хуже 80 м, устаревшем сигнале, резком скачке GPS или уходе с маршрута повороты временно не подсказываются. Прибытие подтверждается только при точности не хуже 35 м и близости к точке маршрута. Если начальная точка далеко, приложение предложит добавить текущую позицию в начало. Автоматического перестроения пока нет: остановите навигацию, обновите старт и постройте путь снова.

Озвучка работает через [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis), предпочитает локальный русский голос, если он установлен. Наличие русского голоса и качество произношения зависят от устройства; некоторые голоса используют онлайн-сервис. При отсутствии синтеза речи остаются текстовые подсказки. Это экспериментальная навигация: дорожные знаки и фактическая обстановка имеют приоритет. Реальная поездка с GPS ещё не проверялась.

Любое изменение точек сбрасывает предыдущий расчёт, чтобы на карте не оставался устаревший путь. Удаление точки, очистку и смену города можно отменить в уведомлении в течение 10 секунд. Последующее изменение списка отменяет предыдущую возможность отката.

## Карты и бесплатные API

Условия проверены 13 ноября 2026 года. Бесплатность приложения для пользователя не означает, что публичные картографические серверы предоставляют неограниченную инфраструктуру.

| Задача | Выбор для прототипа | Ограничения |
| --- | --- | --- |
| Отображение | Leaflet 1.9.4 + стандартные растровые тайлы OpenStreetMap | Ключ не нужен. Видимая атрибуция, обычное HTTP-кеширование, только видимая область; нет массовой или офлайн-загрузки тайлов. Доступность без SLA. |
| Поиск по первым символам | Публичный Photon от komoot | Ключ не нужен. Поддерживает search-as-you-type. Умеренная нагрузка; запрос после паузы 650 мс, не чаще примерно одного запроса в 1,1 с на вкладку, кеш последних 100 запросов. Ограничение страны по ответу, bbox вокруг города и проверка известного названия города/алиасов. |
| Автомобильный путь | Публичный OSRM demo server | Разумное некоммерческое использование, не более 1 запроса/с. Приложение делает один запрос на нажатие и ограничивает повторные запросы. Нет пробок и гарантий доступности. |

Поиск использует `lang=default`: публичный Photon поддерживает `default`, `de`, `en`, `fr`; `lang=ru` возвращает HTTP 400. Запросы на русском и кириллице работают, имена в результатах могут быть русскими или казахскими согласно OSM.

Почему пока не 2ГИС или Google:

- [2ГИС](https://docs.2gis.com/en/maps/overview): нужен ключ; пробный ключ карт действует месяц с лимитом запросов, затем требуется подходящая подписка. Это не основа для обещания постоянной бесплатности API.
- [Google Maps SDK](https://developers.google.com/maps/documentation/android-sdk/usage-and-billing): нативная карта имеет отдельные условия и бесплатную квоту, но требуются API-ключ и billing. [Поиск адресов и Routes оплачиваются по своим SKU и квотам](https://developers.google.com/maps/billing-and-pricing/pricing). У бесплатного для пользователей приложения могут быть расходы разработчика.
- Публичный [Nominatim запрещает autocomplete](https://operations.osmfoundation.org/policies/nominatim/), поэтому в Mapuga он не используется.

Сравнение 2ГИС, Google и Яндекса для актуальных названий организаций, включая ограничения бесплатных тарифов для GPS и сохранения адресов: [docs/map-providers.md](docs/map-providers.md). Сейчас в приложении подключён OpenStreetMap; добавление поиска страны не меняет источник зданий и организаций.

Первоисточники: [Photon и правила demo](https://github.com/komoot/photon#demo-server), [Photon API](https://github.com/komoot/photon/blob/master/docs/api-v1.md), [политика тайлов OSM](https://operations.osmfoundation.org/policies/tiles/), [OSRM demo policy](https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server), [OSRM API](https://project-osrm.org/docs/v26.4.0/http).

Для массового запуска замените публичные demo-серверы на собственные Photon/OSRM или провайдера с подходящим тарифом. Адреса серверов вынесены в `dist/config.js`. Для собственного сервера разрешите CORS для origin приложения. Ограничение частоты в одной вкладке не заменяет общий лимит приложения на серверной стороне.

## Что уже есть и чего пока нет

- Адаптивная раскладка для компьютера и телефона; подсказки стран по первым символам и поиск города из начального справочника.
- Подсказки адресов, проверка дублей и страны, выбор координат на карте, перестановка и удаление остановок.
- Реальный автомобильный путь, расчётные время и расстояние, детализация по участкам и GPX.
- Текущая позиция, GPS-навигация в открытой вкладке, русские текстовые/голосовые манёвры и демонстрация поездки без GPS.
- Локальное сохранение списка, обработка сетевых ошибок, таймаутов и ограничения запросов; защита от запоздавших результатов при изменении города или списка.

Область поиска — прямоугольник вокруг города, а не точная административная граница. Результаты с явно указанным другим городом отбрасываются, но объекты без муниципалитета могут относиться к пригородам. Полнота домов и адресов зависит от OSM. Улица без номера — это точка улицы, а не определённый дом. Маршрутизатор привязывает точки к автомобильной дороге в пределах 1,5 км; о привязке дальше 150 м выводится уведомление. Время не учитывает пробки и остановки.

Пока нет автоматической оптимизации порядка, пешеходных/велосипедных маршрутов, автоматического перестроения, фонового GPS, синхронизации между устройствами или офлайн-карт. Android-оболочку можно добавить вокруг текущих статических файлов следующим этапом.

## Данные

Собственного сервера данных и аналитики нет. План хранится в этом браузере. При поиске Photon получает поисковый текст и область города; при расчёте OSRM получает координаты всех точек; OSM получает запросы видимых тайлов, в том числе при следовании карты за GPS. Геолокация запрашивается только по нажатию соответствующей кнопки. Поток GPS не отправляется в OSRM и не сохраняется в историю; сопоставление с маршрутом выполняется локально. Добавленная по вашей команде стартовая GPS-точка сохраняется как часть плана и при построении передаётся маршрутизатору. Озвучку выполняет выбранный движок речи устройства/браузера. Удаление всех остановок очищает сохранённый список.

`npm test` не обращается к сети. Живой smoke test использует публичные тестовые координаты в Караганде, а не сохранённый пользовательский маршрут. При необходимости `npm run vendor` повторно скачает Leaflet из npm CDN.
